# Local dev convenience install — for a quick venv setup on your own machine.
# Docker builds, the airgap wheel bundle, and native cluster installs do NOT
# read this file; they use the pinned files below so every environment gets
# identical versions:
#
#   requirements-base.txt       - pyspark, psutil, numpy, pandas, etc. (CPU/GPU identical)
#   requirements-torch-cpu.txt  - torch/torchvision CPU build
#   requirements-torch-gpu.txt  - torch/torchvision CUDA 12.8 build (RTX 50-series)
#
# CPU dev setup:
#   pip install -r requirements-base.txt -r requirements-torch-cpu.txt --index-url https://download.pytorch.org/whl/cpu
#
# GPU dev setup:
#   pip install -r requirements-base.txt -r requirements-torch-gpu.txt --index-url https://download.pytorch.org/whl/cu128
-r requirements-base.txt
-r requirements-torch-cpu.txt
